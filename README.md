# 3地点お天気（PWA）

iPhoneのSafariで動く、3地点の「1時間ごとの天気」を確認できるWebアプリ（PWA）です。
ホーム画面に追加すると、ネイティブアプリのように全画面で使えます。

- 天気データ: [Open-Meteo](https://open-meteo.com/)（APIキー不要・無料）
- 地名検索: [Nominatim(OpenStreetMap)](https://nominatim.openstreetmap.org/)（市区町村まで検索可。失敗時はOpen-Meteoに自動切替）
- 地点は地名検索でいつでも3つまで登録・変更可能（例: 船橋市、刈谷市。設定はiPhone内に保存）
- サーバ側の処理なし（静的ファイルのみ）

## 画面でできること

- 3地点をタブで切り替え
- 現在の天気（気温・体感・湿度・風速）
- 48時間先までの1時間ごと予報（気温・降水確率・風速・天気アイコン）を今日／明日…と日別表示
- ⚙️（右上）から地名を検索して各スロットに登録、「📍現在地」も設定可能

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | デザイン（ダーク/ライト自動対応・モバイル最適化） |
| `app.js` | 天気取得・地名検索・描画・設定保存のロジック |
| `manifest.webmanifest` | PWA定義（アプリ名・アイコン・全画面表示） |
| `sw.js` | Service Worker（アプリ本体をキャッシュ、天気は常に最新取得） |
| `icons/` | アプリアイコン（SVG + PNG）と生成スクリプト `gen_icons.py` |
| `start_server.bat` | ローカル配信用の簡易サーバ起動 |

## 使い方（iPhoneで表示する）

iPhoneからアクセスするには、どこかでファイルを配信する必要があります。目的に応じて選んでください。

### 方法A: 自宅/社内PCから一時的に試す（同じWi-Fi）

1. `start_server.bat` をダブルクリック（Python 3 が必要。`py -3` で起動）。
2. 表示された `http://<PCのIP>:8080/` を、**同じWi-Fiに繋いだ**iPhoneのSafariで開く。
3. 共有ボタン → 「ホーム画面に追加」。

> 注意: この方法（http接続）ではService Worker（オフライン機能）は無効ですが、
> 天気表示と「ホーム画面に追加」は問題なく使えます。PCを起動しWi-Fiが必要です。

### 方法B: どこでも常用する（推奨・HTTPS配信）

常にiPhone単体で使うなら、HTTPSの静的ホスティングに置くのが最適です（Service Workerが有効になり、オフライン起動・完全なPWAになります）。

- GitHub Pages / Netlify / Cloudflare Pages などに `weather_pwa` フォルダの中身をそのままアップロード。
- 発行されたHTTPSのURLをiPhoneのSafariで開き、「ホーム画面に追加」。

> 社内ネットワーク/セキュリティ方針によって外部ホスティングの可否が変わります。
> 社内サーバにHTTPSで置ける場合はそちらでも同様に動作します。

## アイコンの再生成

デザインを変えたい場合は `icons/icon.svg` を編集し、PNGを作り直します。

```
cd icons
py -3 gen_icons.py
```

（Pillow が必要: `py -3 -m pip install pillow`）

## 技術メモ / 既知の仕様

- 予報は `forecast_days=3`（最大72時間）取得し、現在時刻以降を最大48時間表示。
- 時刻は Open-Meteo の `timezone=auto`（地点ローカル時刻）をそのまま文字列で扱うため、
  端末のタイムゾーンや海外地点でも時刻がずれません。
- 天気データは10分間だけ画面内にキャッシュし、アプリ復帰時に自動更新します。
- 「現在地」は緯度経度で保存します（地名の逆引きはしていないため表示名は「現在地」）。
